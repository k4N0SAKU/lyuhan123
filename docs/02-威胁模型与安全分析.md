## 1. 参与方与系统假设

### 1.1 参与方（n=3）

| 方 | 角色 | 长期秘密 | 会话秘密 |
|---|---|---|---|
| P0 客户端 | 数据持有方，唯一接触明文输入与最终结果 | SM2 静态私钥、证书 | **CKKS 完整私钥**（掩码解密，D5 修订）、通道密钥 |
| P1 密钥服务节点 | 认证中枢、密钥全生命周期、审计、MPC 参与方 | CA 根私钥、SM2 静态私钥 | 通道密钥（**无任何 CKKS 私钥材料**） |
| P2 推理服务节点 | 模型持有方，密文域计算 | SM2 静态私钥 | 通道密钥（**无任何 CKKS 私钥材料**） |

### 1.2 敌手能力

| 敌手 | 能力 | 不具备 |
|---|---|---|
| 网络敌手（Dolev-Yao） | 窃听/篡改/重放/注入/延迟重组 | 破译 SM2/SM3/SM4-GCM；控制终端内存 |
| 半诚实参与方（static, t=1） | 严格按协议执行但记录全视图 | 偏离协议（恶意行为不设防，可检测不可防） |
| 合谋 | 至多 t=1 方与网络敌手合谋 | t≥2（失效面 §3.3） |

### 1.3 密码假设

SM2/SM3/SM4-GCM 按国标（gmssl + 自实现 GCM，RFC 8998 外部锚定）；SM3 随机
预言机启发；CKKS 128-bit classical（2^15 实测口径，2^16-NONE 备选待 estimator）；
掩码 r/s 均匀一次性（os.urandom）；Beaver 三元组可信离线生成（**D7**）；
时钟偏移 ≤±30s。

### 1.4 安全边界声明（S8）

半诚实 + 恶意网络敌手；**不声称恶意参与方安全**（注入构造性密文/扣留份额=
拒绝服务，可检测不可防）；覆写销毁为进程内存级，不抵御 cold-boot/侧信道
（商用需 TEE）；模型对 P0 公开（docs/01 §2.2）。

## 3. 合谋抵抗分析

### 3.1 视图

P0：明文输入/输出、完整 CKKS 私钥、x+r 掩码解密值。P1：控制面消息、y₁=x+r、
MPC 交互、审计。P2：全部密文（Enc(r)/Enc(s)/Enc(a₁+s)）、−r、模型权重、MPC open。

### 3.2 t=1 抵抗（D5 修订口径）

- **P2 单独**：无钥不可解（RLWE）+ −r 无对照 + open 消息均匀 ⇒ 计算安全；
- **P1 单独**：y₁=x+r 中 r 为 P2 fresh 均匀掩码 ⇒ 信息论一次一密；无钥；
- **P0 单独**：协议流向 P0 的密文仅掩码值与最终输出（解密白名单，docs/01 §8.4）；
  P2 原始中间密文不经手 P0；半诚实下私钥不构成额外能力。⇒ 无超出角色泄露。

### 3.3 t=2 失效面（D3 要求）

| 合谋 | 获得 | 破坏 D3？ |
|---|---|---|
| P1+P2 | y₁+y₂ = x+e：**全部中间态明文** | **是**（掩码分享构造的固有边界） |
| P0+P2 | 全钥+全部密文 ⇒ 全解 | 是 |
| P0+P1 | P0 本就是解密方；P1 无钥可加成 | 是（方案边界） |

结论：安全性精确到 t=1。缓解（扩展，非本期承诺）：2-of-3 门限或 P2 侧盲化。

### 3.4 前向安全

K_{i+1}=SM3(K_i‖H_i)：恢复 K_{i<j} 需逆 SM3（2^256）；审计链同理 append-only。
