## 1. 定点化参数依据（P0 实测，D4/S5/S6）

| 对象 | 方案 | 参数 |
|---|---|---|
| 激活（含 logits） | 定点 Q/DQ，int32 域 | frac_bits 可配置，起步 13，**默认 16** |
| GPT-2 权重 | Q22 定点（线性/卷积/绑定嵌入输出投影统一） | 步长 2⁻²² |
| BERT 权重 | per-输出通道 INT8 | scale=amax/127 |
| bias | 不量化 | 与 INT8 推理实践一致 |
| 溢出策略 | raise（断言）/ clamp | test_quantize 覆盖 |

**GPT-2 生成一致率档位阶梯（20 prompts×16 tokens，P0 实测）**：
INT8 权重 0.891 → FP16 0.944 → Q22+Q13 0.944 → **Q22+Q16 = 1.000**（默认配置）。
BERT 分类：FP32 99.00% → INT8+Q16 **99.00%（下降 0.00pp）**。

**混沌敏感性发现**：logit 近并列 ~1e-5 即可级联发散 ⇒ CKKS 解密噪声（1e-4~1e-1
量级）下密文推理的 token 一致率必然 <1——S6 指标以 logits 相对误差为主、
token 一致率为参考（团队决策项，评审会确认）。

- 消息字段权威载体：`src/protocol/messages.py`（19 类载荷 + CommonHeader
  version/msg_type/session_id(16B)/seq(单调递增)/timestamp_ms(±30s 窗)/payload_len）；

- 模式 B 主线时序：P0 嵌入加密 → [QKV, QK^T] → CONVERT_MASKED_CT(P2→P0) →
  P0 解密 → CONVERT_SHARE(P0→P1) → MPC softmax → RECRYPT_SHARES → [·V, proj]

## 5. CKKS 参数设计

### 5.1 分段刷新定理（模式 B 核心设计）

每次密文↔分享转换返回 fresh 顶层密文 ⇒ 深度重置 ⇒ 模式 B 密文只需**段内
深度 2**（BERT post-LN / GPT-2 pre-LN 均成立，残差经 mod-switch pin 在链底）。
**深度消耗与层数无关**。模式 A 无刷新 → 每层 50 深（P2-R1 校准）→ 12 层 600 深
不可行；本栈深度上限 19 < 50 ⇒ **模式 A 全密文本栈不可演示**（理论推演保留，
团队决策项）。

### 5.3 参数表（P2 实测修订）

| 参数集 | N | 链 | 总位 | 深度 | 槽 | 密文 | 用途 |
|---|---|---|---|---|---|---|---|
| mode-b-segment | 2^15 | [60,40,40,60] | 200 | 2 | 16384 | 1.64MB | 模式 B 主线（10 块/密文，L=16 需 2 密文） |
| deep19-regression | 2^15 | [60]+[40]×19+[60] | 880 | 19 | 16384 | 7.15MB | 噪声回归用 |
| mode-a-THEORETICAL | 2^17 | [60]+[40]×84+[60] | 3480 | 84 | 65536 | - | 本栈不可实例化（需 OpenFHE） |

**实测依据**：本栈（TenSEAL 0.3.14 捆绑 SEAL）对 n≥2^16 一律
invalid_parameters_insecure（与链长无关）；n=2^15 最大链 880bit≤881 通过。
**[评审 C 项]** SEC_LEVEL_TYPE.NONE 下 n=2^16 全链路可用（我方复现 RMSE
1.13e-8）；拒绝根因=TC128 安全表止于 N=32768/882bit（880 过/920 拒）；
**P1 引用"v1.1: 2^16→≤1740bit"有误已更正**（标准表止于 N=32768）。
2^15（转换 192 次、2 密文）vs 2^16-NONE（转换 96 次、L=16 单密文 3.3MB）
取舍待 P3 首日 lattice-estimator（SageMath 环境）后团队决策；**2^16 路线必须
最小步长 Galois 集**（默认全步长 32768 把 >45min 不可行；最小集 68s）。

### 5.4 噪声预算（P2 实测口径）

ε_ckks 为**绝对量**（scale 2^40 下 fresh ~1e-9，每乘 G≈4 增长）：实测模式 B
2 层链 RMSE 3.8e-9、14 层深链 7.1e-9（阈值 1e-6 绝对口径，余量 >100×）。
误差合成 ε_total=√(ε_poly²+ε_ckks²+ε_quant²)，poly 主导。
`invariant_noise_budget` 不支持 CKKS → 观测用 `decrypt_error_rmse`。
旋转噪声实测 ~1e-6 > 乘法噪声（旋转次数进入双重预算）。

## 6. SIMD 打包选型

**对角线 + gap-block(768×2) + BSGS**（`src/model/ops/packing.py`）：
每线性层 768 明文乘（同 level 累加+一次 rescale，净耗 1 深）+ 54 旋转。
**[P2 实测] ρ（旋转/乘）≈1.7（P1 假设 8）→ 排序反转：row-sum 或快 1.3×**
→ P3 双实现 A/B（C3 素材）。实测单层 768×768×L2 = **4.15s**（CPU）。
层间衔接：模式 A 用 replicate_blocks（净耗 1 层）；模式 B 由 P1 转换出口编码
免费重置布局。

### 7.4 模式 B 转换协议（再随机化两侧缺一即为缺陷）

入口：P2 fresh 掩码 r → ct′=ct(x)+Enc_pk(r) → **P0 单钥解密**（白名单内）得
y=x+r+e → CONVERT_SHARE 分发 y₁ 给 P1；P2 持 −r。分享 x = y₁+y₂ (+e_ckks)。
出口：结果分享 (a₁[P1], a₂[P2])；P1 fresh 掩码 s → RECRYPT_SHARES
{Enc(a₁+s), Enc(s)} → P2 密文域合成 fresh 顶层密文（**布局由 P1 编码免费重置**）。
t=1 论证：P0/P1 只见 OTP 掩码值；P2 无钥不可解。**t=2 失效面：P1+P2 合谋
y₁+y₂=x 中间态全失**（docs/02 §3.3）。

### 7.5 MPC 门预算（L=16、2 密文、2^15 口径）

GELU 637k（13 门）+ softmax 95k（31 门/元素）+ LN 197k ≈ **929k 门/层 →
11.2M/请求**；MPC 通信 ≈ **179MB/请求**；转换 192 次 × 7.4MB ≈ **1.42GB**；
在线合计 ≈ **1.60GB/请求**（GB 级结论不变，转换主导）。转换批量合并为 P3
设计约束（I 项）。

## 8. 密钥管理（摘要）

- 状态机 IDLE→NEGOTIATED→ACTIVE→ROTATING→DESTROYED（守卫表+审计，非法转换拒绝）；
- ratchet：K_{i+1}=SM3(K_i‖H_i)，每 64 消息或 5 分钟，旧钥即时覆写；
- SM2DH：gmssl 无高层接口 → 基于底层点乘自实现（J 项闭环，P2 验证 ECDH 原语一致）；
- 销毁：签名指令 → 覆写（随机+0 两遍）→ DESTROYED 终态 → 审计；
- 审计：SM3 哈希链 entry_i.hash=SM3(prev‖canonical(entry_i))，P1 主链 P2 副本。
